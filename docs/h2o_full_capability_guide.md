# H₂O 全能力 DFT/TDDFT 计算操作指南

> 水分子（H₂O）是学习 DFT/TDDFT 的经典体系——足够小（10 电子）能快速算完，又足够复杂（多原子、弯曲结构、有激发态）能展示所有核心功能。本文档覆盖从基态到激发态的全部计算链路。

---

## 第〇章：在开始之前——你需要知道的基本概念

> 如果你对 DFT 完全陌生，先读这一章。如果你已经有基础，直接跳到"前置条件"。

### 0.1 什么是"能级"？

想象一栋楼：每个电子住在一个楼层（能级）里，低楼层便宜（能量低、稳定），高楼层贵（能量高、不稳定）。

```
能量 (eV)
  ↑
  │         ┌───┐  ← 4a₁ (LUMO) — 空房！电子可以被"激发"到这层
  │    -0.8 └───┘
  │
  │         ┌───┐  ← 1b₁ (HOMO) — 住在最高楼层的电子
  │    -7.4 └───┘
  │         ┌───┐  ← 3a₁
  │    -9.3 └───┘
  │         ┌───┐  ← 1b₂
  │   -13.3 └───┘
  │         ┌───┐  ← 1a₁
  │   -24.9 └───┘
  │
  └────────────────── 电子
```

- **每个"楼层"叫一个 KS 轨道**（Kohn-Sham orbital）
- **楼层高度 = 特征值（eigenvalue）**，单位是 eV
- **负值 = 稳定**（电子被原子核束缚住，不会跑掉）
- **正值 = 不稳定**（电子已经跑远了，处于"自由"状态）

### 0.1b 为什么叫 1a₁、1b₁ 而不是 1s、2p？（分子轨道 vs 原子轨道）

你可能学过**原子**的能级：1s, 2s, 2p, 3s... 这些是**氢原子（单个原子核）**的解。

但 H₂O 不是单个原子——它是**三个原子绑在一起**的分子。电子不再绕着某一个原子核转，而是**同时被三个原子核吸引**，在整个分子范围内运动。

**这就改变了规则：**

| | 单个原子（如 O） | 分子（如 H₂O） |
|---|---|---|
| **对称性** | 球对称（像太阳系） | 不对称（水是弯的！） |
| **轨道类型** | s（球形）、p（哑铃形）、d（梅花形） | **分子轨道**——形状由所有原子共同决定 |
| **命名** | 1s, 2s, 2pₓ, 2pᵧ, 2p₂ | a₁, b₁, b₂（对称性标签） |
| **简并度** | p 轨道三重简并（pₓ=pᵧ=p₂） | **简并解除**——分子有方向性，pₓ ≠ pᵧ ≠ p₂ |

#### a₁, b₁, b₂ 是什么意思？

这是**对称性标签**（群论符号），描述轨道在分子的对称操作下如何变换。

H₂O 属于 **C₂v 点群**——它有一条 2 次旋转轴（z 轴）和两个镜面：

```
        z (C₂ 轴)
        ↑
        │
     O  │           H₂O 的 C₂v 对称性：
     ●──┤           - 绕 z 轴转 180°：H₁ 和 H₂ 互换
    ╱   │           - xz 镜面：分子所在平面
   ╱    │           - yz 镜面：垂直于分子平面的面
  H₁    H₂ → x
  ╲    ╱
   ╲  ╱
    yz镜面
```

| 标签 | 含义 | 通俗理解 | 对应哪些原子轨道 |
|------|------|----------|----------------|
| **a₁** | 对所有对称操作都**不变** | "完全对称"——像 s 轨道一样，不管你怎么转都不变 | O 的 2s、O 的 2p₂（沿 C₂ 轴方向）、H 的 1s 组合 |
| **b₁** | 绕 C₂ 转 180° **变号**，但在 yz 镜面**不变** | "垂直于分子平面的哑铃" | O 的 2pₓ（垂直于分子平面） |
| **b₂** | 绕 C₂ 转 180° **变号**，但在 xz 镜面**变号** | "在分子平面内、垂直于 C₂ 轴的哑铃" | O 的 2pᵧ（分子平面内、垂直于 C₂） |

#### 从原子轨道到分子轨道——H₂O 的完整对应关系

```
原子轨道 (O + H)           分子轨道 (H₂O)            能量 (eV)
────────────────────     ──────────────────────    ──────────
                         ┌──────────────────┐
  O 1s (内层，赝势冻结)   │  不参与计算       │    (包含在赝势中)
                         └──────────────────┘

  O 2s ─────────────→    1a₁  (2s + H组合)         -24.9 eV
                              像一个膨大的 s 轨道
                              包住整个分子

  O 2pᵧ + H(1s+1s) ──→  1b₂  (成键轨道)           -13.3 eV
                              两个 O-H 键的"电子桥"
                              ┃ O━━H
                              ┃ O━━H
                              电子在 O 和 H 之间共享

  O 2p₂ + H(1s-1s) ──→  3a₁  (成键+孤对)          -9.3 eV
                              既有成键成分
                              也有 O 自己的电子

  O 2pₓ ─────────────→   1b₁  (纯孤对 = HOMO)     -7.4 eV
                              ★ 完全不参与成键 ★
                              像一个垂直于分子平面的哑铃
                              O 上下的"兔耳朵"
                              这就是为什么水是 Lewis 碱！

                         ──── HOMO-LUMO gap ≈ 6.5 eV ────

  反键组合 ──────────→    4a₁  (反键 = LUMO)       -0.8 eV
                              "反 O-H 键"
                              电子住在这里会削弱化学键
```

**关键洞察：**

1. **1b₁ (HOMO) = O 的 2pₓ**：这个轨道**几乎没变**——它垂直于分子平面，和两个 H 原子没有重叠，所以不参与成键。它是 O 的"私有财产"（孤对电子）。

2. **1b₂ 和 3a₁ 是"新物种"**：它们是 O 的 2p 轨道和 H 的 1s 轨道**混合**产生的，单个原子没有这样的轨道。这是**化学键的本质**——原子轨道组合产生新的分子轨道。

3. **数字前缀**（1a₁, 2a₁, 3a₁...）：同一种对称性 a₁ 的第几个轨道，从低能到高能编号。

4. **为什么不再是 1s, 2s, 2p？** 因为在分子中，电子是**离域的**（delocalized）——不属于某个特定原子。2s 和 2p 的区分只在球对称（单个原子）时才有意义。

### 0.2 HOMO 和 LUMO 是什么？

**HOMO** = Highest **Occupied** Molecular Orbital（最高占据轨道）
- 住在**最高楼层的电子**
- 这个电子最容易被"激发"——因为它离空楼层最近
- **HOMO 能量 ≈ 电离能的负值**（把这个电子踢走需要多少能量）

**LUMO** = Lowest **Unoccupied** Molecular Orbital（最低未占据轨道）
- **最低的空楼层**
- 电子被激发后最可能跳到这里

**HOMO-LUMO Gap** = 两个楼层之间的高度差
- Gap 大 → 电子不容易跳 → 材料是绝缘体（如金刚石）
- Gap 小 → 电子容易跳 → 材料是半导体（如 Si, GaAs）
- Gap = 0 → 电子随便跳 → 材料是金属
- H₂O 的 gap ≈ 6.5 eV → **绝缘体**（所以纯水不导电）

### 0.3 什么是"总能量"？

总能量 = 所有电子的能量 + 原子核之间的排斥 + 电子之间的排斥 + ...

**通俗理解**：把水分子拆成三个独立原子（1个 O + 2个 H）需要的总能量。
- 计算值 ≈ -17.29 Hartree ≈ -470 eV
- 负号表示水分子是稳定的（拆开它需要输入 470 eV 能量）

**为什么要看总能量？**
- 判断计算是否正确（和已知参考值对比）
- 判断分子构型是否稳定（能量越低越稳定）
- 计算化学反应能（产物能量 - 反应物能量）

### 0.4 什么是"收敛"？

DFT 求解是一个**迭代过程**（反复猜 → 算 → 修正 → 再猜）：

```
第1次猜测电子密度 → 算出能量 = -15.0 Ha
第2次用修正后的密度 → 算出能量 = -16.8 Ha
第3次继续修正      → 算出能量 = -17.1 Ha
...
第26次             → 算出能量 = -17.293 Ha
第27次             → 算出能量 = -17.293 Ha  ← 不变了！→ "收敛了"
```

**收敛 = 猜测的结果不再变化了**。SCF 迭代 26 次收敛 = 猜了 26 轮就稳定了。

如果显示 "SCF Converged: ✓ Yes"，说明计算成功。

### 0.5 什么是"电子密度"？

电子密度 n(r) = 空间中每个位置有多少电子

想象你有一张热成像照片：亮的地方电子多（原子核附近），暗的地方电子少（远离原子的区域）。

**2D 切片**：在某个平面上"切一刀"看到的密度分布（像地图上的等高线）
**3D 等值面**：把密度相同的点连成一个面（像地形图上的立体山丘）

### 0.6 什么是"激发态"和"吸收谱"？

**基态 (Ground State)**：所有电子住在最低楼层 → 稳定状态
**激发态 (Excited State)**：某个电子被光"踢"到了更高的楼层

```
基态：                          激发态：
电子电子                         电子
电子电子                         电子电子
电子 ←── 这家伙被光踢上去了 ──→  电子  ← 到了空楼层
───────                        ───────
1b₁ (HOMO)                     4a₁ (LUMO)
```

**吸收谱 = 这分子能吸收哪些颜色的光**

- 横轴 = 光子能量（eV），可以换算成波长/颜色
- 纵轴 = 吸收强度
- 每个峰 = 某个电子跃迁（从某层跳到另一层）

H₂O 主要吸收紫外光（7-13 eV → 95-177 nm），可见光完全透过 → **所以水是透明的**。

### 0.7 PBE vs LDA——两种"计算规则"

DFT 的核心近似是**交换关联泛函 (XC functional)**。你可以把它理解为"电子之间如何互相躲避"的计算规则：

| 泛函 | 类比 | 特点 |
|------|------|------|
| **LDA** | "我只看自己脚下的路况" | 简单快速，但不够准确。倾向于把分子算得太"紧" |
| **PBE (GGA)** | "我也看看周围的路况" | 更准确，但稍慢。分子结构更接近实验值 |

### 0.8 关键术语速查

| 术语 | 一句话解释 |
|------|-----------|
| **SCF** | 自洽场迭代——反复猜电子密度直到收敛 |
| **Hartree** | 原子单位制的能量单位，1 Ha = 27.21 eV |
| **Bohr** | 原子单位制的长度单位，1 Bohr = 0.529 Å |
| **eV** | 电子伏特，一个电子通过 1V 电压获得的能量 |
| **Å** | 埃，1 Å = 10⁻¹⁰ m，原子尺度的标准单位 |
| **赝势** | "假的原子核"——把内层电子冻结，只算外层价电子，省时间 |
| **Spacing** | 实空间网格的间距——越小越精确，但越慢 |
| **Box Radius** | 模拟盒子的大小——越大越精确，但越慢 |
| **ExtraStates** | 额外计算的空轨道数——激发态计算需要更多空轨道 |

## 计算一：基态（Ground State）——"给水分子拍一张X光照片"

### 物理意义

> **类比**：基态计算就像给水分子拍一张"X光照片"——你看不到电子在动（因为绝对零度下电子没有热运动），但你能看到每个电子"住在哪里"。
>
> 具体来说，计算回答这些问题：
> - 水分子的总能量是多少？（它有多稳定？）
> - 每个电子住哪个"楼层"（能级）？（楼层分布图）
> - 电子密度长什么样？（哪里电子多、哪里少？）

### 操作步骤

1. 点击 **H₂O GS** 预设按钮
2. 检查参数面板自动填充：

| 参数 | 预设值 | 通俗解释 | 可调范围 |
|------|--------|----------|----------|
| Calculation Mode | `Ground State (GS)` | 基态——算最稳定状态 | — |
| Molecule | `H₂O — Water` | 水分子 | — |
| Grid Spacing | `0.21` Å | 网格精度——像照片的像素，越小越清晰 | 0.15–0.30 |
| Box Radius | `3.0` Å | 模拟盒子大小——必须把整个分子包住 | 3.0–6.0 |
| Spin Components | `Unpolarized` | 自旋配对——H₂O 的电子都成对 | H₂O 固定 |
| XC Functional | `PBE` | 计算规则——"电子怎么互相躲避"的模型 | PBE 或 LDA |
| Species Mode | `pseudo / standard` | 赝势类型——"假原子核"的来源 | pseudo→PBE |
| Extra States | `4` | 额外空楼层数 | GS 用 4 就够 |
| ncpus / mpiprocs | `64` / `64` | 用多少 CPU 核 | 16–64 |

3. 点击 **Initiate Computation**
4. 等待计算完成（约 2–5 分钟）

### 你会看到什么结果

#### 总能量

```
Total Energy: -17.293 Ha  (≈ -470.6 eV)
```

**这是什么意思？**
- 负号 → 水分子是稳定的（能量越负越稳定）
- 拆成三个原子需要 470.6 eV
- PBE 参考值 -17.293 Ha，LDA 参考值 -17.171 Ha
- 你的结果应该在这个范围 ±0.01 Ha 内

#### 能级分布图

```
轨道名称        能量 (eV)    占据情况    这是什么？
────────────────────────────────────────────────────────
1a₁           -24.86       2 电子      O 的 2s 内层——深埋在原子核附近
1b₂           -13.30       2 电子      O-H 成键轨道——把 H 拉向 O
3a₁            -9.28       2 电子      成键+孤对混合
1b₁ (HOMO)     -7.36       2 电子      O 的孤对电子 ← 最高楼层！
──────────────── HOMO-LUMO gap ≈ 6.55 eV ────────────────
4a₁ (LUMO)     -0.81       空的        最低空楼层 ← 跃迁目标
```

**怎么理解这些数字？**

- **1a₁ (-24.9 eV)**：O 原子的 2s 内层电子。能量很低 = 很稳定 = 不参与化学反应。就像大楼的地基——你拆房子时地基最后才动。
- **1b₂ (-13.3 eV)**：成键轨道。O 和 H 之间的共价键——这就是为什么水不是三个独立原子。
- **3a₁ (-9.3 eV)**：也是成键轨道，但混入了"孤对"成分。
- **1b₁ (-7.4 eV) = HOMO**：**O 的孤对电子**。注意这个轨道不是成键的——它是 O 自己的电子，没有和 H 共享。**这就是为什么水是好的 Lewis 碱**——O 的孤对电子可以"送给"别的分子的空轨道（比如 H⁺ → 形成 H₃O⁺）。
- **4a₁ (-0.8 eV) = LUMO**：最低的空轨道。能量接近 0 = 电子住在这里几乎不被束缚 → "反键"轨道（如果电子真的跳到这里，O-H 键会变弱）。

**HOMO-LUMO Gap = 6.55 eV**：
- 这个 gap 很大 → 纯水是绝缘体
- 对比：Si 的 gap ≈ 1.1 eV（半导体），Au 的 gap = 0（金属）

#### SCF 收敛过程

```
SCF Converged: ✓ Yes
SCF Iterations: 26
```

**这意味着什么？** 计算程序猜了 26 轮电子密度分布，最终结果不再变化了。26 次是一个正常数字——说明计算稳定。

如果 SCF 不收敛（比如 >200 次还没稳定），通常是因为参数设置有问题（见"常见问题"）。

#### 电子密度可视化

计算完成后自动生成两张"照片"：

- **2D 切片**：某个平面上的电子密度热图。你会看到 O 原子附近特别亮（电子密集），H 原子次之，远处是黑的。
- **3D 等值面**：立体的电子云形状。像一团包裹着分子的"雾"，O 附近最浓，两侧有 H 的小突起。

## 计算二：Casida 线性响应（激发态）——"水分子能吸收什么光？"

### 物理意义

> **类比**：基态是水分子"安静坐着"的状态。现在我们想知道：如果用不同颜色的光照水分子，哪些颜色的光会被吸收？
>
> Casida 方法就像**先算出吉他弦的所有可能谐振频率**——不实际拨弦，而是用数学公式直接算出来。结果是：每个激发态的精确能量 + 每个跃迁有多强（振子强度）。

### 你在计算什么

每个"激发"就是一个电子从某层跳到更高层：

```
跃迁 1: 1b₁ → 4a₁   需要能量 = 4a₁能量 - 1b₁能量 ≈ -0.8 - (-7.4) = 6.6 eV
跃迁 2: 3a₁ → 4a₁   需要能量 = -0.8 - (-9.3) = 8.5 eV
跃迁 3: 1b₂ → 4a₁   需要能量 = -0.8 - (-13.3) = 12.5 eV
... 以及所有其他可能的跳跃
```

但 Casida 比简单的"楼层高度差"更精确——它考虑了电子跳上去之后，其他电子也会跟着调整（"电子关联"效应）。

### 操作步骤

1. 点击 **H₂O Casida** 预设按钮
2. 注意参数变化：

| 参数 | 变化 | 为什么 |
|------|------|--------|
| Calculation Mode | → `Casida` | 切换到激发态模式 |
| Box Radius | → `5.0` Å | 激发态电子更弥散，需要更大盒子 |
| XC | → `LDA` | **Octopus 16.0 限制：Casida 只支持 LDA** |
| Species Mode | → `builtin_standard` | 内置赝势匹配 LDA |
| Extra States | → `13` | 需要 13 个空轨道构建完整激发矩阵 |
| Casida KS States | → `1-16` | 用前 16 个轨道（5 占据 + 11 虚） |

3. 点击 **Initiate Computation**
4. 等待完成（约 5–10 分钟，server 内部先跑 GS 再跑 Casida）

### 你会看到什么结果

#### 激发态表格

```
激发 #    能量 (eV)    波长 (nm)    振子强度    含义
──────────────────────────────────────────────────────────
  1        6.83        181         0.048      最弱的吸收
  2        8.40        148         0.000      暗态！（看不到）
  3        8.74        142         0.081      中等
  4        9.23        134         0.013      弱
  5        9.54        130         0.016      弱
  ...
  最强     ~12.7        98          ~0.24     最亮的吸收峰
──────────────────────────────────────────────────────────
总计: 48 个激发态
```

**逐行解释：**

- **激发 1 (6.83 eV, 弱)**：HOMO → LUMO 跃迁。一个孤对电子被激发到反键轨道。振子强度 0.048 = 很弱 → 这个跃迁"不太被允许"（和光的偏振方向不完全匹配）。
- **激发 2 (8.40 eV, f=0.000)**：**暗态**。数学上存在这个激发态，但它的对称性使得它**完全不吸收任何方向的光**。就像一根吉他弦某个谐振模式你永远听不到一样。
- **激发 3 (8.74 eV, 中等)**：较强的吸收。对应实验中 ~9.9 eV 的吸收带。
- **最强峰 (~12.7 eV)**：多个跃迁叠加的明亮激发态。

**为什么 48 个激发态？**
- H₂O 有 5 个占据轨道 × 多个虚轨道 = 很多可能的跃迁
- 减去对称性禁戒的（不吸收光的）= 48 个

#### 吸收谱图

Casida 结果会被展宽成一条连续曲线（像实验测到的光谱）：
- 横轴：光子能量 (eV)
- 纵轴：吸收强度
- 每个竖线是一个激发态，被展宽后连成平滑曲线

#### 和实验对比

| 我们的结果 | 实验值 | 偏差 | 原因 |
|-----------|--------|------|------|
| 第一激发 6.83 eV | 7.4 eV | 偏低 0.6 eV | LDA 的系统误差 |
| 主峰 ~8.7 eV | ~9.7 eV | 偏低 ~1 eV | LDA 低估激发能 |
| 有 Rydberg 峰 | 有 | 定性正确 | |

> **LDA 为什么偏低？** LDA 低估了 HOMO-LUMO gap（"导数不连续"问题），所以算出来的激发能普遍偏低。用 HSE06 或 GW+BSE 可以大幅改善，但 Octopus 16.0 Casida 不支持这些。

## 计算三：TDDFT 时域传播——"给水分子一巴掌，看它怎么晃"

### 物理意义

> **类比**：
>
> Casida 是"先算好吉他弦的所有谐频再弹"。
> TDDFT 是"直接拨弦，录音，做频谱分析"。
>
> 具体做法：
> 1. 先让水分子安静地处于基态（电子都在最低楼层）
> 2. 突然给一个瞬时电脉冲（"delta-kick"——"踢一脚"）
> 3. 电子被扰动，开始在楼层间振荡
> 4. 记录偶极矩随时间的变化（振荡信号）
> 5. 对时间信号做**傅里叶变换** → 得到频率域的吸收谱

```
时间域（我们记录的）              频率域（我们想要的）
                                   
偶极矩 ↑     ╱╲╱╲╱╲╱╲           吸收强度 ↑  ╱╲
       │    ╱            ╲                │ ╱  ╲     ╱╲
       │   ╱              ╲               │╱    ╲   ╱  ╲
       │──╱                ╲──→ 时间      └──────────────→ 能量
       └── kick!           衰减振荡         峰 = 吸收频率
```

**为什么这个方法好？**
- 一次计算得到整个吸收谱（不需要逐个算激发态）
- 可以处理非线性效应（强场、高阶过程）
- 对大体系更有优势（Casida 计算量 ∝ N⁴，TDDFT 只 ∝ N²-N³）

**代价是什么？**
- 能量分辨率取决于传播时间：时间越长 → 分辨率越高
- 25000 步 ≈ 500 a.u. 传播时间 → 分辨率 ≈ 0.34 eV（比较粗糙）
- 要得到 0.1 eV 分辨率需要 85000 步（计算时间翻 3 倍）

### 操作步骤

1. 点击 **H₂O TDDFT** 预设按钮
2. 检查参数：

| 参数 | 预设值 | 通俗解释 |
|------|--------|----------|
| Excitation Type | `delta` | 瞬时脉冲——"踢一脚" |
| Polarization | `x` (direction 1) | 踢的方向（x 轴） |
| Field Amplitude | `0.01` | 踢的力度——必须轻，保持"线性响应" |
| TD Time Steps | `25000` | 记录多少个时间点 |
| TD Time Step | `0.02` a.u. | 每个时间点的间隔 |
| 总传播时间 | 500 a.u. ≈ 12 fs | Steps × dt |

3. 点击 **Initiate Computation**
4. **等待 20-40 分钟**（25000 步传播 + 傅里叶分析）

**关键参数的直觉：**

- **dt = 0.02 a.u.**：时间步长。太大 → 数值不稳定（电子飞走了）。太小 → 相同物理时间需要更多步。0.02 是对 spacing=0.21 Å 的安全值。
- **Steps = 25000**：更多步 → 更长传播时间 → 更高频率分辨率 → 但更慢。
- **Amplitude = 0.01**：kick 太强（>0.1）→ 电子被踢飞了，不再是线性响应。太弱（<0.001）→ 信号太弱，噪声大。

### 你会看到什么结果

#### 吸收谱

一条连续曲线，横轴是光子能量 (eV)，纵轴是吸收截面 (Å²)。

**主要特征：**

```
吸收强度
  ↑
  │         ╱╲
  │        ╱  ╲              ╱╲
  │   ╱╲  ╱    ╲      ╱╲  ╱  ╲         ╱╲
  │  ╱  ╲╱      ╲    ╱  ╲╱    ╲   ╱╲  ╱  ╲
  │ ╱            ╲  ╱          ╲ ╱  ╲╱    ╲
  │╱              ╲╱                    ╲
  └──────────────────────────────────────────→ 能量 (eV)
  0    5    10    15    20    25
        ↑           ↑           ↑
      ~6.4 eV    ~8.8 eV    ~12.7 eV
      (HOMO→LUMO) (主峰)     (Rydberg)
```

- **~6.4 eV 弱峰**：HOMO→LUMO 跃迁（很宽，因为分辨率只有 0.34 eV）
- **~8.8 eV 主峰**：最明亮的激发态 ← 这应该和 Casida 的 8.74 eV 吻合
- **~12.7 eV**：Rydberg 态区
- **16-20 eV 尾部**：电离连续态（电子被完全踢飞了）

#### 偶极矩时间序列

还会看到偶极矩随时间的振荡衰减曲线：
- 开始时有一个突变（kick！）
- 然后电子来回振荡
- 逐渐衰减（因为多个频率叠加导致退相干）

### Casida vs TDDFT 对比

两者算的是**同一个物理量**（吸收谱），但方法不同：

| | Casida | TDDFT |
|---|---|---|
| **方法** | 解矩阵方程 | 模拟时间演化 |
| **类比** | 算吉他弦理论频率 | 直接拨弦录音分析 |
| **输出** | 离散的激发态（精确峰位） | 连续谱（受分辨率限制） |
| **速度** | 快（小分子 <10 min） | 慢（>20 min） |
| **精度** | 峰位精确，但只有单激发 | 连续谱，分辨率取决于传播时间 |
| **局限性** | 只能描述单激发；O(N⁴) | 分辨率受传播时间限制 |
| **适合** | 小分子精确激发态 | 大分子、非线性、超快过程 |

**交叉验证**：两者的主峰应该吻合（差异 < 0.2 eV）。如果不吻合，说明某个计算有 bug。

## 计算四：未占据态（Unoccupied States）——"看看空房间长什么样"

### 物理意义

> 基态计算只给了我们 5 个占据轨道 + 少量空轨道。但 Casida 需要知道更多空轨道的信息（因为电子可以被激发到任意空楼层）。
>
> Unocc 计算就是"打开更多楼层的门看看"——多算 12 个虚轨道。

### 操作步骤

1. 选择 **H₂O GS** 预设，然后手动修改：
   - Calculation Mode → `Unoccupied States`
   - Extra States → `12`（5 占据 + 12 虚 = 17 总态）
   - Eigen Solver → `chebyshev_filter`（Octopus 16.0 推荐的高效算法）
2. 点击 **Initiate Computation**

### 你会看到什么

能级图扩展了：

```
占据轨道（已有）        虚轨道（新增）
1a₁  -24.9 eV          4a₁  -0.8 eV  (LUMO)
1b₂  -13.3 eV          2b₂   0.3 eV  ← 新算出来的
3a₁   -9.3 eV          5a₁   0.8 eV  ← 新算出来的
1b₁   -7.4 eV (HOMO)   2b₁   1.5 eV
                          6a₁   2.1 eV
                          ...更高效值变正（连续态）
```

**注意**：虚轨道能量越高越不准确。最上面的几个虚轨道基本就是"数值噪声"。真正有用的是 LUMO 附近的前 5-8 个虚轨道。

## 计算五：几何优化（Geometry Optimization）——"让分子自己找到最舒服的姿势"

### 物理意义

> 我们目前用的 H₂O 坐标是"别人给的最佳猜测"。但如果这个猜测不完美呢？
>
> 几何优化让计算机自动微调每个原子的位置，找到**能量最低的构型**——也就是最稳定的键长和键角。
>
> **类比**：把一个球放在碗里，球会自己滚到碗底。GO 就是让原子"滚到能量最低的位置"。

### 操作步骤

1. 选择 **H₂O GS** 预设，然后手动修改：
   - Calculation Mode → `Geometry Optimization`
   - Box Shape → **`Sphere`**（必须！`minimum` 不会随原子移动更新）
   - Box Radius → `5.0` Å（给原子移动留余量）
2. 点击 **Initiate Computation**

### 你会看到什么

| 量 | 优化前 | 优化后 | 实验 |
|----|--------|--------|------|
| O-H 键长 | 0.957 Å | ~0.97 Å | 0.958 Å |
| H-O-H 角 | 104.5° | ~104° | 104.5° |

优化过程就像爬山（下坡）：
```
步骤 1: 能量 = -17.28 Ha
步骤 2: 能量 = -17.31 Ha  ← 原子稍微动了
步骤 3: 能量 = -17.32 Ha
...
步骤 N: 能量不再变化 → 收敛！
```

## 计算六：振动模式（Vibrational Modes）——"水分子怎么颤？"

### 物理意义

> 分子不是刚体——原子在平衡位置附近不停振动。H₂O 有 3 个原子，3×3-6 = **3 个振动自由度**。
>
> 每个振动模式有特定频率，对应红外光谱中的一个吸收峰。

### H₂O 的三种振动模式

```
ν₁ 对称伸缩 (~3657 cm⁻¹)     ν₂ 弯曲 (~1595 cm⁻¹)     ν₃ 反对称伸缩 (~3756 cm⁻¹)

  O                           O                           O
 ╱ ╲                         ╱ ╲                         ╱ ╲
H   H   ←→                  H   H    ↕                  H   H
                               ↑                       →      ←
两个O-H键同相伸缩              H-O-H角度变化              两个O-H键反相伸缩
```

### 操作步骤

1. 先完成 **GS** 或 **GO**
2. Calculation Mode → `Vibrational Modes`
3. 点击 **Initiate Computation**

## 可视化功能详解

所有可视化按钮位于结果面板底部 **"3D 可视化"** 区域。

### 波函数 1D——"某个轨道长什么样"

- **操作**：点击"波函数 1D" → 点击"▶ 渲染"
- **你看到什么**：一条曲线，展示某个轨道的波函数值沿 x 轴的变化
- **怎么读**：波峰 = 电子出现概率高的位置；波节（过零点）= 电子永远不出现的边界
- **选择不同态**：State 1 = 最深层的 1a₁，State 4 = HOMO 1b₁，State 5 = LUMO 4a₁

### 密度 2D 切片——"在某个平面上切一刀看电子密度"

- **操作**：点击"密度 2D切片" → 点击"▶ 渲染"
- **你看到什么**：彩色热图。亮区 = 电子密集，暗区 = 电子稀疏
- **参数**：
  - Slice Axis：在哪个方向切片（x/y/z）
  - Slice Position：在哪个位置切片（0 = 通过 O 原子中心）
  - Colormap：颜色方案（plasma = 紫黄渐变，推荐）

### 电子云 3D——"完整的立体电子云"

- **操作**：点击"电子云 3D" → 点击"▶ 渲染"
- **你看到什么**：一个立体曲面，像包裹着分子的"气球"
- **等值面的含义**：曲面上每个点的电子密度相等。就像地图上的等高线——同一条线上高度相同。
- **Isovalue**：阈值。数值越大 → 只保留密度最高的核心部分（小而紧凑）。数值越小 → 包含更多弥散的电子云（大而蓬松）。
- **自动快照**：计算完成后自动生成 3D PNG（marching cubes 算法）

### 吸收谱——"分子吸收了哪些光"

- **操作**：点击"吸收谱" → 点击"▶ 渲染"（仅 TD/Casida 模式可用）
- **Casida 模式**：每个竖线是一个激发态，被展宽后连成平滑曲线
- **TDDFT 模式**：从偶极矩傅里叶变换得到的连续谱

## XC 泛函选择指南

| 场景 | 推荐 XC | 赝势 | 原因 |
|------|---------|------|------|
| **快速 GS 预览** | LDA (PZ81) | builtin_standard | 最快 |
| **精确 GS 能量** | PBE | pseudo / standard | 更准确 |
| **Casida 激发态** | LDA (PZ81) | builtin_standard | **Octopus 16.0 限制** |
| **TDDFT 吸收谱** | LDA 或 PBE | 匹配即可 | 无 XC kernel 限制 |
| **几何优化** | PBE | pseudo / standard | 更接近实验 |

> **核心规则：赝势集必须匹配 XC 泛函**
>
> - `builtin_standard`（PSF/HGH）→ **LDA XC**
> - `pseudo` / `standard`（UPF/ONCV, PAW-PBE）→ **PBE XC**
>
> 混用 → SCF 不收敛。Server 会自动检查并修正。

### 能力 1-2：基态 + 电子密度（GS）

**对应 15_DFT_TDDFT.md 第二章（DFT 基础）**

DFT 把"10 个电子的多体波函数"简化成"一张电子密度图 n(r)"。对于 H₂O：
- 总能量 -17.293 Ha (PBE) → 和实验自洽
- 5 个 KS 轨道的特征值 → 对应分子能级
- 电子密度 → 告诉你 O-H 键上电子如何分布

**KS 特征值的物理含义：**

严格来说，KS 特征值不是"真实"的轨道能量（只有 HOMO 有明确的物理意义 ≈ -IP）。但在实践中，它们和实验光电子谱吻合得很好，可以定性理解电子结构。

```
实验光电子谱 (XPS)          我们的 DFT 计算
─────────────────          ────────────────
峰 ~540 eV (O 1s)          ← 被赝势冻结，不计算
峰 ~32 eV  (O 2s)          1a₁ = -24.9 eV  (偏低，但定性正确)
峰 ~19 eV  (1b₂)           1b₂ = -13.3 eV  (偏低)
峰 ~15 eV  (3a₁)           3a₁ = -9.3 eV   (偏低)
峰 ~12.6 eV (1b₁)          1b₁ = -7.4 eV   (HOMO, Koopmans 近似)
```

> **为什么偏低？** 这就是 `15_DFT_TDDFT.md` 里说的"导数不连续"问题——半局域泛函 (PBE/LDA) 系统性地低估轨道能量。杂化泛函 (HSE06) 可以改善。

### 能力 3-4：线性光学——吸收谱（Casida + TDDFT）

**对应 15_DFT_TDDFT.md 第三章（TDDFT）和第四章（吸收谱方法选择）**

15_DFT_TDDFT.md 提供的**决策树**对 H₂O 的适用：

```
H₂O 是分子（不是固体）→ 跳过"独立粒子近似"和"BSE"
                     → 直接用 Casida 或 TDDFT
                     → 因为 H₂O 没有"带"结构（能带是固体的概念）
```

**H₂O 吸收谱的两个视角：**

| 方法 | Casida (LR-TDDFT) | TDDFT (RT-TDDFT) |
|------|-------------------|-------------------|
| 对应 15_DFT 的哪个章节 | 3.2 "线性响应" | 3.2 "实时传播" |
| 给你什么 | 精确的离散激发态能量 + 振子强度 | 连续吸收截面谱 |
| 优点 | 峰位精确；可以直接看到每个跃迁 | 包含所有阶次响应；一次得到完整谱 |
| 缺点 | 只有单激发；O(N⁴) | 分辨率取决于传播时间 |
| H₂O 的关键结果 | 48 个激发态，首次 6.83 eV | 主峰 ~8.8 eV，与 Casida 交叉验证 |

**和实验对比：**

| 特征 | 我们 (LDA) | 实验 | 偏差原因 |
|------|-----------|------|---------|
| 第一激发 | 6.83 eV | 7.4 eV | LDA 低估 gap (15_DFT 2.4节) |
| 第一吸收带 | ~9-10 eV | ~10 eV | 定性正确 |
| Rydberg 态 | ~13 eV | ~13-14 eV | 需更大盒子 |

> **如何改善？** 根据 15_DFT_TDDFT.md 4.2 节，用 DDH 泛函可以接近 BSE 精度。但 Octopus 16.0 Casida 限制 LDA kernel。长期方案是升级到支持 PBE Casida 的 Octopus 版本。

### 能力 5：几何优化（GO）

DFT 不仅可以算固定几何的能量，还可以让原子**自动移动到能量最低的位置**。

对于 H₂O，这是验证我们输入坐标是否合理的好方法：
- 输入 O-H 键长：0.957 Å → 优化后：~0.97 Å → 实验：0.958 Å ✓
- 输入 H-O-H 角：104.5° → 优化后：~104° → 实验：104.5° ✓

### 能力 6：振动模式（Vib）

对应 15_DFT_TDDFT.md 中提到的"红外光谱"计算。

H₂O 的振动模式是红外光谱的经典教学案例：

```
   ν₁ 对称伸缩            ν₂ 弯曲               ν₃ 反对称伸缩
   ~3657 cm⁻¹             ~1595 cm⁻¹             ~3756 cm⁻¹

    ←O→                   ↕                      ←    →
   H    H               H    H                  H      H
   ←  →                   ↑↓                    →      ←

   两个O-H同相伸缩        H-O-H角度变化           两个O-H反相伸缩
   (对称拉长)             (像剪刀)                (一拉一缩)
```

这些频率可以在实验室用 FTIR 光谱仪直接测量 → DFT 计算是**预测红外光谱**的有力工具。

### 能力 7-10：进阶 TDDFT

#### 未占据态（Unocc）✅

这是 Casida 的前置步骤——多算一些"空楼层"，让激发态计算有足够的目标轨道。

#### 非线性光学 / HHG ✅

15_DFT_TDDFT.md 3.3 节提到 RT-TDDFT 可以算 HHG（高次谐波产生）。

**原理：** 用强激光（正弦波）照射分子。电子在强场下做非线性振荡，辐射出频率为基频整数倍的"高次谐波"——就像用力拨吉他弦，弦不仅发出基频，还会发出泛音。

**H₂O HHG 结果（800nm 驱动）：**

```
谐波阶次    能量 (eV)    物理含义
──────────────────────────────────────
H1         34          基频响应 + 低阶非线性
H2        118          二次谐波
H3        203          三次谐波（奇次为主）
H4        287          四次谐波
H5        329          ...
H6        371          趋近截止能
H7        447          截止区

基频 = 0.057 a.u. = 1.55 eV (800nm Ti:Sapphire)
传播时间 = 20.3 a.u. = 0.49 fs (50000 步)
```

**操作：** 点击 "H₂O HHG" 预设按钮，自动设置 sin 波激发参数（spacing=0.35, 50000 步）。计算约 15-20 分钟。

#### 超快动力学 / 泵浦-探测 ✅

泵浦-探测光谱 = 用一个短脉冲（Gaussian 形状）激发分子，然后观察电子如何随时间演化。

**原理：** 就像用闪光灯拍照——脉冲越短，你能"冻结"的电子运动越快。Gaussian 脉冲包含宽频成分，所以一次激发可以覆盖多个吸收峰。

**操作：** 点击 "H₂O Pump" 预设按钮。Gaussian 脉冲参数：幅度=0.01, t₀=500, σ=100。

#### Floquet 工程 / 连续波 ✅

用连续周期光照射分子，看有效能级如何被光场修改。

**原理：** 就像在荡秋千时有人持续推你——如果推动频率和秋千频率匹配，振幅会越来越大（共振）。Floquet 理论告诉我们，周期驱动等效于在能量空间中产生"副本"能级。

**操作：** 点击 "H₂O CW" 预设按钮。连续余弦波参数：幅度=0.005, 频率=0.057 a.u. (800nm)。

## 常见问题与排查

### MCP 显示 Offline

SSH 隧道断开了：
```bash
ssh -f -N -L 8000:localhost:8000 dirac-key
```

### Casida 报 FATAL

用了 PBE XC 做 Casida → 改回 LDA。用 "H₂O Casida" 预设按钮最安全。

### TDDFT 太慢

25000 步需要 20-40 分钟，这是正常的。可以先减少到 5000 步快速看效果，但分辨率会差很多。

### 3D 电子云空白

HPC 上需要 scikit-image：
```bash
ssh dirac-key "pip install scikit-image"
```

### SCF 不收敛

三个最常见原因：
1. 赝势与 XC 不匹配（builtin_standard + PBE = 灾难）
2. 盒子太小（radius < 3.0）
3. 间距太大（spacing > 0.3）

### 吸收谱噪声多

传播时间不够 → 分辨率不足 → 频谱泄漏。增加 TD steps（50000+）。

## 参数收敛测试——"怎么知道我的参数够不够好？"

> **收敛** = 参数变一点，结果基本不变 = 你选的参数够了。

### Spacing 收敛（网格精度）

| Spacing (Å) | 总能量 (Ha) | HOMO (eV) | 和上一个的差异 |
|-------------|------------|-----------|---------------|
| 0.30 | 自己跑 | 自己跑 | — |
| 0.21 | -17.293 | -7.36 | 基准 |
| 0.15 | 自己跑 | 自己跑 | 应该 < 0.001 Ha |

如果 0.21→0.15 的能量差 < 0.001 Ha，说明 0.21 够了。

### Radius 收敛（盒子大小）

| Radius (Å) | 总能量 (Ha) | 和上一个的差异 |
|------------|------------|---------------|
| 3.0 | -17.293 | — |
| 4.0 | 自己跑 | 应该 < 0.01 Ha |
| 5.0 | 自己跑 | 应该 < 0.001 Ha |
| 6.0 | 自己跑 | 应该 < 0.0001 Ha |

### XC 泛函对比

| XC | 总能量 (Ha) | HOMO (eV) | Gap (eV) | 激发能偏差 |
|----|------------|-----------|----------|-----------|
| LDA | -17.171 | -7.46 | 6.53 | 偏低 0.5-1 eV |
| PBE | -17.293 | -7.36 | 6.55 | 偏低 0.3-0.5 eV |
